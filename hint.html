2階　赤の部屋

ロックのかかったトランク

トランクのスロットには、それぞれⅠ・Ⅱ・Ⅲ・Ⅳsと表示されています。 どこか別の場所で、このローマ数字を見かけませんでしたか？
例えば、バスルームの鏡にはⅠと書かれています。

バスルームの鏡にはⅠ、赤の部屋のランプにはⅡ、廊下の時計にはⅢ、赤の部屋の小机にはⅣと書かれています。 トランクのスロットを回してみてください。それぞれ曜日を設定できるようです。 ローマ数字が書かれた場所と曜日には、何か関係があるのではないでしょうか？

それぞれの物を表す漢字の「偏」に注目してみてください。
例えば、Ⅰの「鏡」は何偏でしょうか？

Ⅰの「鏡」は金偏なので Friday、
Ⅱの「灯」は火偏なので Tuesday、
Ⅲの「時」は日偏なので Sunday、
Ⅳの「机」は木偏なので Thursday です。

パソコン：月の満ち欠けの暗号

パソコンのPINコードを入手するには、月の満ち欠けの暗号を解く必要があります。
えんぴつを使うと、どこかから4つの月を見つけられるかもしれません。

小机の上にある紙をえんぴつでこすってみてください。
上に置かれていた紙の筆圧が残っていたようで、4つの月が浮かび上がります。
この4つの月は、部屋にあるカレンダーを使って数字に置き換えることができます。

浮かび上がった月の形を、そのまま読むとは限りません。
えんぴつでこすって白く見えている部分は、元の紙ではどのように描かれていたでしょうか？

浮かび上がった月は、右半月・新月・満月・左半月に見えます。
しかし、えんぴつでこすって白く浮かび上がった部分は、元の紙では黒く描かれていたと考えられます。

そのため、月の形を逆に考えると、左半月・満月・新月・右半月になります。
カレンダーと照らし合わせると、それぞれ12日・5日・20日・28日です。

PINコードは 1252028 です。

パソコン：ヨーロッパ旅行の暗号

パソコンには3×3の9つの点が表示されています。点から点へとなぞると線が引けます。
この点とヨーロッパ地図を見比べてみてください。 9つの点は、それぞれヨーロッパの国を表しているようです。

小机の上の紙は読みましたか？
旅の経路に関するルールが書かれています。 赤の部屋にある3枚の搭乗券も見比べながら、旅の経路を考えてみてください。

旅の経路は次のようになります。

イギリス → ドイツ → ノルウェー → フィンランド → ポーランド → ルーマニア → イタリア → スペイン → フランス → イギリス

これを9つの点に当てはめると、次の順番になります。

左上 → 中央 → 上中央 → 右上 → 右中央 → 右下 → 下中央 → 左下 → 左中央 → 左上

キッチン＆リビングルーム

カラフルな棚

中央のガラスの扉を開くには、すべての引き出しを閉じる必要があるようです。
ただし、引き出しは好きな順番で閉められるわけではありません。 次にどの引き出しを閉めることができるのか、そのルールを探してみてください。

各引き出しには、取っ手と本体にそれぞれ色がついています。 引き出しを閉める順番と、この2つの色には何か関係があるのではないでしょうか？

取っ手の色は、次に閉めることのできる引き出しの本体の色を示しています。

例えば、「茶色の取っ手・黒の本体」の引き出しを閉めた場合、 次に閉めることができるのは「茶色の本体」の引き出しです。

閉める順番は一通りではありません。 このルールに従って、すべての引き出しを閉じてみてください。

通気口の奥のアイテム

通気口の奥には、2つのアイテムが落ちています。 それぞれを手に入れるには、別のアイテムが必要なようです。

左側のカードは、何かの磁力を利用すると取れそうですね。
右側のアイテムは、必ずしも実物そのものを手に入れる必要はなさそうです。

左側のカードは、冷蔵庫にあるマグネットを使って取ることができます。
右側のアイテムは、インスタントカメラで写真に撮ることで、コードの写真を手に入れることができます。

ガレージ

ブレーカーの落とし方

キッチンに貼ってある注意書きは読みましたか？

黄色のトースターのダイヤルを回し、電子レンジのスタートボタンを押してみてください。 さらに、ケトルをセットして電源を入れてください。 ケトルはガレージにありますよ。

UFOの給水方法

ガレージにある机の下が容器でふさがっています。 容器は床に接着剤で張り付いているようです。消毒用アルコールスプレーを使ってみてください。 青の部屋に空のスプレー、1階のバスルームの棚に消毒用アルコールがありますよ。

容器をどけると、壁に穴が空いているのが分かります。 穴を触って、ホースを差し込んでみてください。 この穴はどこにつながっているのでしょうか？

穴は庭につながっているようです。 庭に出て、差し込んだホースを確認してみてください。 ホースを蛇口につなぐには、もう少し長さが必要なようですね。 どこかにホースを延長できるものはないでしょうか？

1階バスルームの棚にある延長ホースを使って、ホースを蛇口につなげてください。 蛇口から水を出すのも忘れないでくださいね。

UFOの帰還先コード

UFO内部にある舵ハンドルを回して、帰還先コードを入力する必要があるようです。 帰還先コードの手掛かりは、黒の部屋にあるノートに書かれています。 ノートを読むには、特殊な眼鏡が必要ですね。

ノートには「帰還先コードは自室から観測可能」と書かれています。 しかし、黒の部屋の窓は黒く塗りつぶされていて、外を見ることができません。 窓にアルコールスプレーを吹きかけてみてください。 空のスプレーは青の部屋、消毒用アルコールは1階のバスルームの棚にありますよ。

窓から空を観察するには、望遠鏡を使ってみてください。 帰還先コードが数字として見えるはずです。 でも、UFOに入力する必要があるのは数字ではないようですね。

眼鏡を装着していると、空に浮かぶ暗号が解読され、数字として見えるようです。 しかし、UFOに入力する必要があるのは、解読される前の暗号です。 眼鏡を外した状態でもう一度望遠鏡をのぞいてみてください。 6つの記号が見えるはずです。 その6つの記号を、UFOの舵ハンドルを使って順番に入力してください。
